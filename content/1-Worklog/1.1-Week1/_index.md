### Week 1 Achievements:

- Understanding Cloud Computing:

  - Cloud computing refers to delivering IT resources over the Internet, eliminating the need to invest in physical infrastructure.
It follows a pay-as-you-go pricing model — you're charged based on actual usage.
This helps optimize costs since you're not paying for idle resources, while still maintaining high performance.
Resources can be scaled up or down flexibly depending on real-world demand.
It operates on a global scale, making it accessible and applicable anywhere in the world.

  - How to approach learning Cloud Computing:

Exchange knowledge and learn from those with more experience in the field.
Get hands-on practice by working directly with AWS services.
Supplement learning through self-study on online platforms.

  - Setting up an AWS account and getting familiar with its tools:

Successfully created an account and received $200 in credits after completing the activation tasks.
Gained a clear understanding of the distinction between Root User and IAM User:
The Root User is the primary account with full control over the entire system.
IAM Users are sub-accounts created by the Root User and assigned specific permissions.
Enabled Multi-Factor Authentication (MFA) to strengthen account security.

  - Steps to create a User in IAM:

Go to the AWS Console and search for IAM (Identity and Access Management).
On the Dashboard, pay attention to two key sections: Users and User Groups.
Select Users → Create user.
Enter a username, optionally enable AWS Management Console access, then choose the password creation method for the IAM user.
Click Next, then Create user to finish.

  - Steps to create a User Group in IAM:

Go to the AWS Console and search for IAM.
Select User Groups → Create user group, name the group, and create it.
Open the newly created group, click Add user, select the user(s) to add, and confirm.
